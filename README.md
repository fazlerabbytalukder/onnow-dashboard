# OnNow — Admin Dashboard

A modern, responsive admin dashboard built with React, Vite and Tailwind CSS.

## ✨ Features

- Responsive dashboard layout with sidebar navigation
- Analytics charts with **ApexCharts**
- **Customer table** and a reusable data table component
- Swiper carousels for highlighted content
- Client-side routing with React Router
- Reusable component structure

## 🧰 Tech Stack

| Area | Tools |
| --- | --- |
| Framework | React, Vite |
| UI | Tailwind CSS, React Icons |
| Charts | ApexCharts, react-apexcharts |
| Other | React Router, Swiper |

## 🚀 Getting Started

```bash
git clone https://github.com/fazlerabbytalukder/onnow-dashboard.git
cd onnow-dashboard
npm install
npm run dev
```

Then open `http://localhost:5173` in your browser.
